About This Course

This is a comprehensive development course covering Rails 8 + React/Next.js application development with a focus on:

  • 37signals/One Person Framework patterns
  • Maquina tools (generators, UI components)
  • Claude Code AI-assisted development
  • Tailwind CSS for styling
  • Mobile development (Android/iOS) alongside web

Audit System

Systematic checklist for each chapter - audit your app against the codebase

🔍
What is the Audit System?

This system allows you to audit your app against the 259-step codebase chapters. It includes:

  • Chapter Checklists - Detailed checklist for each chapter (ch01-ch10)
  • Agent Skills - Reusable audit tasks for Claude Code / OpenCode agents
  • Audit Runner - Bash script to run quick checks
🛠️
How to Run Audits

Method 1: Quick Audit Runner (Bash)

# Run all chapter audits
./audit_runner.sh all

# Run single chapter audit
./audit_runner.sh chapter1
./audit_runner.sh 3

# Run security audit
./audit_runner.sh security

# Check pre-launch items
./audit_runner.sh pre-launch

Method 2: Agent Skills (Claude Code / OpenCode)

Use the Task tool with skills defined in audit_skils.md:

# Chapter audit example
Task(
  description: "Audit Chapter 3",
  prompt: "",
  subagent_type: "explore"
)

# Security audit
Task(
  description: "Security Audit",
  prompt: "",
  subagent_type: "explore"
)

Method 3: Read the Checklists

Open these files in your editor:

  • audit_checklist.md - Full checklist (all chapters)
  • audit_skills.md - Agent skills (copy-paste prompts)
  • README.md - App status & TODOs
📝
Audit Checklist Files
FileDescriptionLocation
audit_checklist.md Full checklist based on 10 chapters (259 steps) your-app/audit_checklist.md

Since you're using OpenCode (or Claude Code), you can create a custom command or skill that runs the full audit automatically:

To audit your app against the codebase chapters, run:
