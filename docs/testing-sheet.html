A Rails 8.1 progressive web app for cycle tracking. Users log moods, symptoms, superpowers, and period data. The app runs as a PWA in mobile browsers (Safari, Chrome). Admin panel at /admin manages users, content, and inbox.

How to use this sheet
Step through section by section
1. Enter your name at the top.

2. Work through each tab in order. The tab bar shows your pass/total count per section.

3. Click any test row to expand the step-by-step instructions.

4. Set the status to Pass, Fail, or leave as Pending.

5. Add notes — include error messages, screenshots, or observations.

Results auto-save to your browser. Use Export CSV to share results.
