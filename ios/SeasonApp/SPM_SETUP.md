# Season iOS App (Hotwire Native)

## Using Swift Package Manager (Recommended - No CocoaPods needed!)

Since Xcode is not yet installed, we'll use **Swift Package Manager** instead of CocoaPods.

### When Xcode is installed:

1. Open `SeasonApp.xcodeproj` in Xcode
2. Go to **File → Add Packages**
3. Enter URL: `https://github.com/hotwiredev/hotwire-native-ios`
4. Select **"Add Package"**
5. Update `SceneDelegate.swift` to use SPM-imported HotwireNative
